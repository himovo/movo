# 核心会话浏览器用例

入口、账号和证据要求见[总清单](browser-release-cases.zh-CN.md)。每项均通过浏览器操作候选部署；网络请求可辅助核对，不能替代页面结果。使用每次发版独有的数字标记，避免旧数据误判。

| 编号 | 操作 | 必须看到的结果 |
| --- | --- | --- |
| U01 | A 登录，点“新建对话”，发送包含本次标记的简短任务；等待运行结束，再刷新并从历史打开。 | 只有一条对应用户消息和完整回答；发送按钮恢复；刷新后的会话 ID、消息和回答一致。HTTP 200 或出现部分流文本本身不算完成。 |
| U02 | 在 U01 会话连续追问前一轮标记，再要求结合前两轮回答；切到别的会话后返回并刷新。 | 第二、三轮分别引用正确标记和上下文；消息按提交顺序各出现一次；刷新后每轮回答内容一致。固定响应模型桩只能验证传输与持久化，不能宣称上下文正确。 |
| U03 | 新会话发送可持续运行的任务，出现流式输出时点“停止”；记录停止后的文本，再发送新任务。 | 停止状态结束、输入可用；等待一小段时间并刷新，旧任务不继续追加内容或覆盖新回答；新任务正常完成。若任务太快结束，应更换慢任务重测。 |
| U04 | A 创建有有效期的分享链接；B 用独立上下文打开链接并登录；B 发一条带标记消息，A 再回复。 | B 能看到加入前历史、A 的作者身份；A、B 都能看到对方消息及正确作者，刷新后仍一致。链接令牌不残留在加入后的地址栏。 |
| U05 | 在 U04 会话，A 移除 B；B 刷新并尝试发送。另建分享链接，A 撤销后用未加入的独立上下文尝试旧链接；已加入成员可再测主动退出。 | 被移除或退出者无法继续读取、发送；撤销的链接不能用于新加入；A 仍能读取原会话。分别记录“成员移除”和“链接撤销”，不能互相替代。 |
| U06 | A 发送必须调用已授权只读工具才能得到固定测试值的任务；展开执行区并刷新。 | 执行区显示目标工具的实际调用、成功状态和结果；最终回答与结果一致；刷新后调用记录仍在。仅模型声称“已调用”不算通过。 |
| U07 | 在输入框用 `/` 选定已发布 Skill，检查选中标签后发送固定任务；观察请求和执行区并刷新。 | 请求关联目标 `selected_skill_id`；执行过程或产出包含该 Skill 的独有可核验结果；刷新后可回看。通用回答不算通过。 |
| U08 | A 连续创建两个带不同标记的私有会话，往返切换；B 独立登录搜索这些标记。 | A 两个会话的 ID、消息及回复不串；B 不能读取 A 的私有历史或附件。共享会话须按 U04 单独验证。 |
| U13 | 对持续运行的任务，在输出中刷新页面；另一次在输出中切换到其他会话再返回。 | 页面显示运行中或已结束的真实状态；完成后每条消息只有一份，执行记录与回答对应；输入最终恢复。不要在同一任务上同时做刷新和切换。 |
| U14 | 用隔离测试环境制造一次模型、工具或知识检索失败，查看页面；恢复依赖后在同会话发送新任务。 | 失败有明确可见状态，不显示为成功结果；不会永久占用输入框；恢复后的新任务能完成，历史失败记录仍可辨认。无法安全制造故障时记“阻塞”，不得以正常成功路径替代。 |
| U15 | 对测试会话依次搜索、置顶、改名、取消置顶，再删除另一个测试会话；A 退出登录并尝试回到私有会话地址，之后重新登录。 | 搜索结果与标题匹配；排序或置顶状态、改名及删除刷新后正确；退出后私有内容不可访问，重新登录后未删除会话还在。 |
| U33 | 分别在运行中和任务终止后验证会话生命周期：①在 U03 停止任务并确认旧输出冻结后，同一会话发送一个新标记任务；②从该已停止会话点“新建对话”，发送不同标记；③返回旧会话继续追问，再刷新并往返切换；④另在 U14 失败后新建会话并发送独立任务。 | 停止只终止目标任务；同会话后续任务和新会话均可完成。新会话拥有不同会话 ID 和独立历史；旧会话恢复后旧任务不续写、不覆盖新会话回答、不产生重复消息/工具副作用。失败会话保留可辨认错误，另一新会话不继承其运行中或错误状态。若页面提供显式重试按钮，额外重试一次并确认只产生一个最终结果；未提供则记“不适用”，不得自行假设有重试功能。 |
| U21 | 在用户设置中切换为 English，刷新并重新登录，再切回中文；每种语言下走新建会话、多轮追问、停止、上传文件、查看产物卡片和触发一个可恢复错误。 | 导航、按钮、状态、错误提示、时间或数字格式随语言切换，刷新和重登后偏好保持；回复内容、用户输入和文件名不被错误翻译；两种语言下任务、下载及恢复均可用。记录任何残留写死中文或英文的界面位置，必要时截图。 |

记录每一步的会话 ID、标记、开始和结束时间、截图或 trace。分享与隔离必须分别注明 A、B 使用的上下文；不要把浏览器的同一个已登录窗口当作第二账号。
