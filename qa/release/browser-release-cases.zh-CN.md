# 发版前浏览器验收用例

候选版本部署后，在本会话用 Codex 浏览器操作**候选环境**。`qa/release-smoke.spec.ts` 仅是基础对话自动化，不代表全套通过。不要用旧候选版本或开发服务器的结果替代本次结果。

## 准备与记录

- 记录候选 Git 提交、镜像版本、用户端及管理后台 URL、浏览器、执行时间及启用能力；准备管理员和同企业普通用户 A、B 的独立浏览器上下文。测试账号不得含客户数据。
- 固定测试数据：唯一数字标记、可持续运行的任务、输出可核验的只读工具、已发布且结果可核验的 Skill、无敏感内容的文件和知识样本。翻译样本见 `fixtures/release-translation-source.txt`。每次运行另生成一个独有的文章标记供 U18、U19 复用。
- 每项记为**通过 / 失败 / 阻塞 / 不适用 / 待服务器验证**，写下会话 ID、实际结果和截图或 trace。阻塞与待服务器验证均不算最终通过；不适用仅可用于本次确实未启用的能力，并记录依据。

## 必跑：会话与任务

逐步操作和断言见[核心会话用例](browser-release-core-cases.zh-CN.md)。

| 编号 | 场景 | 最低通过条件 |
| --- | --- | --- |
| U01 | 登录、新建会话、首轮任务 | 消息和最终回答出现；刷新后仍可从历史打开。 |
| U02 | 多轮上下文和切换 | 第二、三轮正确引用唯一标记；消息顺序和内容在切换、刷新后保持。 |
| U03 | 停止运行并继续发送 | 停止后不再追加旧输出；输入恢复；同会话新任务完成。 |
| U04 | 双账号分享与实时协作 | B 用链接加入；A、B 看到历史、作者和双方新消息。 |
| U05 | 移除成员、撤销链接、退出 | 失去权限的一方不能再读取或发送；所有者会话仍在。 |
| U06 | 实际执行工具 | 有真实调用及成功结果；回答与工具输出一致；刷新后记录保留。 |
| U07 | 选择并执行 Skill | 选中目标 Skill；请求关联正确 Skill；执行结果可核验；刷新后保留。 |
| U08 | 会话、账号隔离 | 两个会话不串消息；A、B 的私有会话及附件互不可见。 |
| U13 | 运行中刷新与恢复 | 刷新或切换后状态收敛，最终消息不重复，后续仍可发送。 |
| U14 | 失败后的恢复 | 服务或工具失败有明确提示，不伪装成功；后续任务仍可完成。 |
| U15 | 会话管理和重新登录 | 搜索、置顶、改名、删除生效；退出后私有内容不可见，重新登录后仍在。 |
| U33 | 会话停止、恢复与重新开始 | 覆盖运行中页面恢复、停止后同会话续发、停止/失败后新建会话，以及往返切换旧会话；会话 ID、消息和任务状态不串、不重复。 |
| U21 | 中英文界面与任务回归 | 切换中文、英文并刷新；在两种语言下执行新建、多轮、停止、文件产物和错误提示的代表路径；语言偏好持续生效。 |

## 按启用能力必跑

步骤见[扩展能力用例](browser-release-capability-cases.zh-CN.md)。能力在本次候选版本的用户端可见或开放给目标用户时，就属于“启用”。

| 编号 | 场景 | 最低通过条件 |
| --- | --- | --- |
| U09 | 文件与产物 | 上传、解析、问答、来源或产物下载形成闭环；失败文件有明确状态。 |
| U10 | 知识文档学习与检索（PDF、Word、Excel、PPT） | 管理后台上传 PDF、DOCX、XLSX、PPTX 四份固定样本，逐份学习/索引成功；用户端在对应知识范围内检索出独有标记、正确事实和匹配来源；刷新后仍有效；坏文件错误与重试可验证。旧版 DOC/PPT/XLS 若仍宣称支持也要分别覆盖。 |
| U11 | 定时任务 | 创建、触发、编辑或停用、删除均符合实际执行结果和时区。 |
| U12 | 桌面 Code / 浏览器 Agent | 若本次同时发布桌面能力，在对应客户端验证权限、执行和结果。 |
| U16 | 插件生命周期 | 安装或上传、校验、启用调用、停用及移除的结果正确。 |
| U17 | 工作流 Skill 生命周期与分享 | 新建工作流类型，配置节点和只读工具，测试、发布并在对话中实际调用；如开放分享，B 可接收且撤权有效。 |
| U18 | 文章生成与 Word 交付 | 页面显示 `.docx` 下载卡片；文件可下载、打开，内容包含本次文章标记；刷新后卡片保留。 |
| U19 | 同一文章导出 PDF | 页面显示独立 `.pdf` 下载卡片；文件可下载、打开，内容与 U18 一致；刷新后卡片保留。 |
| U20 | 文档翻译与 Word 交付 | 上传英文样本并译成中文；关键术语、数字和结构准确；译文 `.docx` 卡片与下载文件有效。 |

## 本轮模块拆分专项

逐步操作和断言见[模块拆分专项用例](browser-release-refactor-cases.zh-CN.md)。本轮同时改动用户端会话布局、输入框、Skill/工具/演示文稿，以及管理后台的知识文档、Skill/工具配置，须在两个已登录入口执行对应流程。

| 编号 | 场景 | 最低通过条件 |
| --- | --- | --- |
| U22 | 导航、侧栏和历史搜索 | 切换、搜索、返回及刷新后状态正确，宽窄视口布局正常。 |
| U23 | 输入框、选择项与附件 | 模型/Skill/知识选择、输入法、附件预览和发送准确。 |
| U24 | 流式回答与消息渲染 | 执行记录和最终回答不重复，切换与刷新后可回看。 |
| U25 | 用户端工作流 Skill 配置 | 新建工作流，配置节点和工具，测试、保存重开、发布并在对话中实际调用。 |
| U26 | 用户端工具配置 | 字段推断、测试、保存及实际调用一致。 |
| U27 | 演示文稿编辑器 | 编辑、撤销/重做、保存重开、预览与导出正确。 |
| U28 | 文档生成跨模块链路（服务器） | Word/PDF 卡片与下载内容正确，刷新后仍可用。 |
| U29 | 提示词引导 | 建议填入、取消和发送不覆盖已有输入或重复提交。 |
| U30 | 图表、Mermaid、来源与文档编辑 | 渲染、来源定位、编辑保存/取消及刷新结果正确。 |
| U31 | 账号、企业与分享落地 | 身份和数据范围正确，切换与重登后无私有数据串漏。 |
| U32 | 用户端写作风格 Skill | 配置、测试、发布及对话实际调用一致。 |
| A01 | 管理后台知识文档 | 目录、筛选、批量上传、预览和删除状态正确。 |
| A02 | 管理后台工具编辑 | 字段配置、测试、保存重开与用户端调用一致。 |
| A03 | 管理后台工作流 Skill 配置 | 新建工作流，配置节点和工具，测试、发布并在用户端实际调用。 |
| A04 | 管理后台语言和布局 | 中英文、刷新、弹窗与窄屏布局正常。 |
| A05 | 管理后台写作风格 Skill | 结构/约束、脚本节点、测试和用户端调用一致。 |

桌面模块拆分另有 [D01–D02 桌面客户端用例](browser-release-refactor-cases.zh-CN.md)；D01 明确覆盖新建空目录项目、项目列表及重启后的持久化。Web 浏览器不能代替桌面客户端验收。本次若只发布服务器镜像，记录桌面能力不在发布范围；若发布桌面端，则必须实际启动桌面客户端完成 D01–D02，不能以 Web 端项目/会话替代。

## 发版判定

本地阶段先完成具备条件的用户端、管理后台用例，形成“本地回归结果”；U18–U20、U28 的文档交付闭环，以及依赖相同渲染环境的 U27，安排在最终候选版本部署服务器后验证。本地环境缺失导致的未执行项标记“待服务器验证”，不得据此宣布完整发版验收通过；服务器阶段须使用同一最终候选提交及镜像补齐证据。

U01–U08、U13–U15、U18–U24、U29–U31、U33、A01–A04 全部通过，且所有启用能力对应的 U09–U12、U16–U17、U25–U28、U32、A05 全部通过，才能报告“浏览器验收通过”。若发布桌面客户端，D01–D02 也必须在实际桌面客户端全部通过；若未发布桌面客户端，记录不适用及版本范围。Word、PDF 或译文缺卡片、无法下载、文件打不开或内容不符，均记失败；模型文字声称“已生成”不算交付。缺第二账号、可核验工具、Skill 或慢任务环境时，先补齐再执行，不能把必跑项记为通过。每次形成一份[报告模板](browser-release-report-template.zh-CN.md)格式的报告，记录每项状态及证据。失败修复后，在**同一最终候选提交和部署**重新跑受影响链路及核心回归。

自动化基础回归见[执行说明](browser-release-e2e.md)；现有分享专项 `qa/session-sharing-realtime.spec.ts` 需要专门 QA 种子环境，不属于默认发版套件。U18–U21 当前按浏览器步骤执行，不能将基础 smoke 通过视为这些用例通过。
