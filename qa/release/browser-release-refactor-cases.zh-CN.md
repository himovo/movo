# 模块拆分专项浏览器回归

针对本轮用户端页面、会话、输入框、Skill、工具、演示文稿，以及管理后台知识文档、Skill、工具和相关后端模块的拆分。使用候选部署与隔离测试数据；每项在操作后刷新或重开，核对持久化结果。不得在客户数据上验证删除。

## 执行与证据

- 本地先执行 U22–U26、U29–U32、A01–A05；U25、A03 必须走“新建工作流 Skill → 配置 → 测试 → 发布 → 对话实际调用”的闭环。缺少测试模型或工具时先准备隔离样本，阻塞不得记为通过。
- 当前本地环境不具备完整文档交付条件。U18–U20、U28 留到候选版本部署服务器后执行；本地记录为“待服务器验证”，不能记通过，也不能因本地环境缺失把业务判为失败。U27 若依赖同一文档/演示渲染环境，也在服务器执行并注明依据。
- 每项记录页面 URL、测试对象 ID、独有标记、操作前后截图、刷新/重开结果及失败时的控制台或网络错误。Word、PDF 和演示文稿须核对下载文件内容。
- 仍须执行 U01–U21 的适用项；专项回归不能替代登录、分享、权限、隔离、失败恢复及中英文业务路径。
- D01–D02 仅在桌面客户端执行；本地 Web 浏览器的 U/A 用例通过不能证明这两项通过。若本次只发布服务端镜像，报告中注明桌面客户端不在发布范围。
