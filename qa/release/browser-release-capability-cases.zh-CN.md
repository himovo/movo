# 扩展能力浏览器用例

适用性与发版判定见[总清单](browser-release-cases.zh-CN.md)。仅在候选版本对目标用户开放对应能力时执行。所有样本使用隔离测试数据；删除本次创建的插件、Skill、知识和定时任务时先保存证据。

| 编号 | 操作 | 必须看到的结果 |
| --- | --- | --- |
| U09 | 上传含唯一标记的支持格式文档，等附件准备完成后要求引用其内容；如支持产物生成，再创建并下载产物。另试不支持或损坏的文件。 | 消息显示正确附件；回答引用样本值而非臆造；来源或下载文件可打开且内容正确；刷新后附件和来源仍在。无效文件明确报错且未被静默丢弃。 |
| U10 | **四种格式分别独立验证，不得只抽测一种**：在管理后台目标知识目录依次上传 `fixtures/release-learning-ppt.pptx`、`release-learning-excel.xlsx`、`release-learning-word.docx`、`release-learning-pdf.pdf`。每份等待解析、分段和学习/索引状态完成后，在绑定同一知识范围的用户端全新会话中，按文件名询问其中唯一标记及对应事实，并打开来源。刷新后台和用户端后复核状态与引用。最后用隔离的损坏文件验证失败提示和重试。 | 每种格式都必须独立达到：后台上传文件名正确；解析及学习/索引状态成功且分段数大于 0；用户端回答同时返回该文件独有标记及事实值（PPT：`QA_PPT_20261103` / `Indigo-42`；Excel：`QA_EXCEL_20261103` / `Maple-28`；Word：`QA_WORD_20261103` / `Cedar-17`；PDF：`QA_PDF_20261103` / `Quartz-93`）；来源名称确为对应文件且片段含标记/事实；刷新后仍可检索。任何格式解析成功但索引失败、无来源、串到其他文件或只回答对但来源缺失均记失败。损坏样本须显示可理解的失败状态，修复/重新上传后可恢复。 |
| U11 | 创建近期一次性任务，选“每次执行新建会话”，核对页面时区和计划时间；等触发并打开生成的会话。再创建周期测试任务，编辑提示词、停用并观察一个调度窗口，最后删除。 | 一次性任务按计划触发一次，生成的会话和结果正确；编辑保存后页面显示新配置；停用或删除后无新增执行。运行窗口要覆盖实际计划时间，不能只凭开关状态判定。 |
| U12 | 若随版发布桌面 Code 或浏览器 Agent，在对应桌面客户端用隔离工作区执行一个可验证任务，并检查权限提示、执行记录和产物。 | 权限与任务实际需要相符；执行记录和最终产物一致；失败可见且可恢复。纯 Web 版不适用时注明发布范围。 |
| U16 | 在“插件”页安装或上传已知安全的测试插件，执行校验并启用；从对话中调用其只读能力；随后停用再尝试调用，最后移除。 | 插件列表、校验和启用状态正确；启用时有实际工具调用与固定结果；停用或移除后不可再成功调用该插件。仅看到插件卡片不算通过。 |
| U17 | **新建工作流类型 Skill**，配置至少两个可区分的节点，其中一个调用隔离的只读测试工具；保存、运行配置页测试并发布/启用。在用户端新会话用 `/` 选择该 Skill，发送带独有标记的任务；展开执行过程并刷新重开。修改一个可发布节点后再执行。如开放分享，A 分享给 B，B 接收并执行，随后撤销访问。 | 创建类型确为工作流；节点顺序、工具调用和测试结果可核验；对话请求关联目标 Skill，执行记录有实际节点/工具结果，最终回答与结果一致；刷新后记录保留。更新后的版本对应新配置；B 只在授权期可用。仅创建、发布或模型声称执行均不算通过。 |
| U18 | 新建会话，要求生成约 300 字中文文章《发版验收报告》，含本次独有标记、标题、两小节和结论，并导出 `movo-release-article.docx`；等待完成，点击回答下方 Word 卡片的下载按钮，打开文件；刷新后重开。 | 正文和文件均含标记及结构；`.docx` 卡片可见且文件可下载、打开；刷新后卡片仍可用。仅文字声称导出不算通过。 |
| U19 | 在 U18 会话要求将同一文章另导出 `movo-release-article.pdf`，保留标记、标题、小节和结论；点击 PDF 卡片下载，打开文件；刷新后重开。 | 独立 `.pdf` 卡片可见；PDF 可打开、中文无乱码和空白页，内容与 Word 的标记及关键段落一致；刷新后仍可下载。Word 卡片不能代替 PDF 卡片。 |
| U20 | 新建会话，上传 `fixtures/release-translation-source.txt`，要求译成中文、保留标题、两条要点、数字 `73421` 和术语 `MOVO`，并导出 `movo-release-translation.docx`；下载、打开，刷新后重开。 | 译文语义及结构正确，数字和术语不变；译文 `.docx` 卡片、下载和文件内容均正确；刷新后附件引用与卡片仍在。只输出译文文本不算交付通过。 |

文件和知识测试应分别进行：聊天附件属于 U09，管理后台知识文档的学习、索引、用户端检索和来源属于 U10；若候选版还提供用户个人知识，另按其产品入口验证个人范围与隔离。U10 四份固定样本见 `fixtures/release-learning-*`；四种格式逐份记录解析状态、索引状态、分段数、问答标记、来源文件名及刷新后的状态。当前知识上传界面接受 `.pdf/.doc/.docx/.ppt/.pptx/.xls/.xlsx` 等类型；上述四份覆盖 PDF、DOCX、PPTX、XLSX 主流格式，若候选版本继续宣称支持旧版 DOC/PPT/XLS，则还须各加一份旧格式回归，不能从新版格式通过推定旧版通过。定时任务至少记录计划时间、页面时区、实际触发时间及会话 ID，方便判断偏差。U18–U20 的 Word/PDF/翻译文件交付在本地环境不具备条件时，保留步骤并标记“待服务器验证”；候选版本部署服务器后必须下载并检查文件内容，不能用本地文字回答或部分卡片代替。
