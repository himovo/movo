# Arctic Frost

A cool and crisp winter-inspired theme that conveys clarity, precision, and professionalism.

## Color Palette

- **Ice Blue**: `#d4e4f7` - Light backgrounds and highlights
- **Steel Blue**: `#4a6fa5` - Primary accent color
- **Silver**: `#c0c0c0` - Metallic accent elements
- **Crisp White**: `#fafafa` - Clean backgrounds and text

## Color Roles (Recommended)

- **Primary visual anchor**: Use **Steel Blue** (`#4a6fa5`) for key titles, major cards, and progress emphasis.
- **Secondary support tone**: Use **Silver** (`#c0c0c0`) for separators, soft labels, and secondary UI surfaces.
- **Highlight tint**: Use **Ice Blue** (`#d4e4f7`) for subtle chart fills and lightweight callout areas.
- **Content surface**: Use **Crisp White** (`#fafafa`) for text-heavy regions and readable cards.

## Practical Usage Rules

- Keep page palette to **1 dominant cool tone + 1 support tone + neutral surface**.
- Use ice blue as a soft accent only; avoid full-page ice-blue washes.
- Preserve high readability with dark text on white/frost surfaces.
- Prefer rounded rectangles for process nodes and data cards.
- Keep connector lines thin (`1-2px`) and visually secondary.

## Suggested Layout Color Mapping

- **Cover / hero page**: steel-blue anchor region with ice-blue light accents.
- **Agenda / timeline page**: white/frost cards, steel-blue steps, silver separators.
- **Architecture / framework page**: white modules, steel-blue headers, ice-blue highlights.
- **Data / chart page**: steel-blue primary series, ice-blue secondary series, silver grids.

## Do / Don't

- **Do** keep a clean, clinical, professional look.
- **Do** use silver for structure, not for primary emphasis.
- **Don't** stack multiple pale backgrounds and lose contrast.
- **Don't** make every element blue; keep neutral breathing space.

## Typography

- **Headers**: DejaVu Sans Bold
- **Body Text**: DejaVu Sans

## Best Used For

Healthcare presentations, technology solutions, winter sports, clean tech, pharmaceutical content.
