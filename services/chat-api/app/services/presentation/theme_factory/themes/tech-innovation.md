# Tech Innovation

A bold and modern theme with high-contrast colors perfect for cutting-edge technology presentations.

## Color Palette

- **Electric Blue**: `#0066ff` - Vibrant primary accent
- **Cyan**: `#22d3ee` - Controlled highlight color
- **Dark Gray**: `#1e1e1e` - Deep backgrounds
- **White**: `#ffffff` - Clean text and contrast

## Color Roles (Recommended)

- **Primary visual anchor**: Use **Electric Blue** (`#0066ff`) for key titles, primary nodes, and major emphasis blocks.
- **Secondary highlight**: Use **Cyan** (`#22d3ee`) for inline text emphasis, trend lines, key numeric highlights, and interaction cues. Never use as large-area background-color.
- **Large dark base**: Use **Dark Gray** (`#1e1e1e`) for hero backgrounds, side panels, or contrast zones.
- **Content surface**: Use **White** (`#ffffff`) for readable content cards and text-first regions.

## Practical Usage Rules

- Keep palette disciplined per page: usually **1 dominant base + 1 accent + neutral text/surface**.
- Title and key visual should prioritize **Electric Blue**; chart highlights may use **Cyan**.
- For dark-background slides, keep text high contrast (white or near-white) and avoid low-contrast cyan-on-light areas.
- Use containers only when they explain ownership or grouping; vary silhouettes and avoid card walls.
- Connector lines should be thin and clean (`1-2px`), visually behind nodes when forming timelines.

## Suggested Layout Color Mapping

- **Cover / hero page**: dark base (`#1e1e1e`) + blue/cyan light accents.
- **Agenda / timeline page**: white or very light neutral surface, blue primary nodes, cyan emphasis only on current stage.
- **Architecture / framework page**: white content cards with blue headings and cyan micro-highlights.
- **Data / chart page**: bar/line hierarchy can use `#0066ff`, `#22d3ee`, `#1e1e1e`, and white/gray background for separation.

## Do / Don't

- **Do** keep strong hierarchy and generous whitespace.
- **Do** use cyan as highlight, not as full-page fill color.
- **Don't** apply one light cyan tint to all large page surfaces.
- **Don't** mix too many bright accents in the same region.

## Typography

- **Headers**: DejaVu Sans Bold
- **Body Text**: DejaVu Sans

## Best Used For

Tech startups, software launches, innovation showcases, AI/ML presentations, digital transformation content.
