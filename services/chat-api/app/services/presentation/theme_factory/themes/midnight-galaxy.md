# Midnight Galaxy

A dramatic and cosmic theme with deep purples and mystical tones for impactful presentations.

## Color Palette

- **Deep Purple**: `#2b1e3e` - Rich dark base
- **Cosmic Blue**: `#4a4e8f` - Mystical mid-tone
- **Lavender**: `#a490c2` - Soft accent color
- **Silver**: `#e6e6fa` - Light highlights and text

## Color Roles (Recommended)

- **Primary visual anchor**: Use **Deep Purple** (`#2b1e3e`) for hero backgrounds and dominant contrast zones.
- **Secondary structure tone**: Use **Cosmic Blue** (`#4a4e8f`) for section headers and key cards.
- **Highlight accent**: Use **Lavender** (`#a490c2`) for callouts, node emphasis, and data highlights.
- **Content surface**: Use **Silver** (`#e6e6fa`) or white-tinted panels for readable content blocks.

## Practical Usage Rules

- Keep pages disciplined: **one dark cosmic base + one cool accent + neutral text surface**.
- Use lavender as selective emphasis, not as broad background.
- Ensure dark-on-light or light-on-dark contrast is explicit.
- Prefer rounded rectangle cards; avoid overly decorative cosmic shapes.
- Use clean thin connectors (`1-2px`) and keep them behind labels/nodes.

## Suggested Layout Color Mapping

- **Cover / hero page**: deep-purple base with cosmic-blue gradients and lavender highlights.
- **Agenda / timeline page**: silver/white surface, cosmic-blue steps, lavender current-step cue.
- **Architecture / framework page**: silver cards, purple headings, lavender micro-highlights.
- **Data / chart page**: cosmic-blue primary series, lavender secondary, purple baseline/axis anchors.

## Do / Don't

- **Do** keep dramatic contrast with controlled highlight usage.
- **Do** preserve clean hierarchy even in dark mode compositions.
- **Don't** fill all large panels with lavender.
- **Don't** over-layer gradients that reduce text clarity.

## Typography

- **Headers**: FreeSans Bold
- **Body Text**: FreeSans

## Best Used For

Entertainment industry, gaming presentations, nightlife venues, luxury brands, creative agencies.
