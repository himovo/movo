# Forest Canopy

A natural and grounded theme featuring earth tones inspired by dense forest environments.

## Color Palette

- **Forest Green**: `#2d4a2b` - Primary dark green
- **Sage**: `#7d8471` - Muted green accent
- **Olive**: `#a4ac86` - Light accent color
- **Ivory**: `#faf9f6` - Backgrounds and text

## Color Roles (Recommended)

- **Primary visual anchor**: Use **Forest Green** (`#2d4a2b`) for dominant sections and headline emphasis.
- **Secondary structure tone**: Use **Sage** (`#7d8471`) for medium-priority cards and dividers.
- **Highlight color**: Use **Olive** (`#a4ac86`) for subtle callouts, icons, and data highlights.
- **Content surface**: Use **Ivory** (`#faf9f6`) or white for text-heavy panels.

## Practical Usage Rules

- Keep pages grounded: **green-led base + one muted accent + neutral surface**.
- Use olive as highlight only; avoid large olive background blocks.
- Ensure text contrast remains strong on ivory and sage surfaces.
- Prefer rounded rectangles for process and scenario cards.
- Keep line work minimal and thin (`1-2px`), using sage/olive for secondary emphasis.

## Suggested Layout Color Mapping

- **Cover / hero page**: forest-green anchor panel with sage accents.
- **Agenda / timeline page**: ivory surface, green nodes, olive current-step emphasis.
- **Architecture / framework page**: ivory cards, green titles, sage separators.
- **Data / chart page**: forest-green primary series, olive secondary, sage grid/labels.

## Do / Don't

- **Do** keep a calm, natural, trustworthy visual tone.
- **Do** prioritize whitespace and clear card rhythm.
- **Don't** fill large zones with olive and reduce contrast.
- **Don't** use all earth tones at equal prominence in the same area.

## Typography

- **Headers**: FreeSerif Bold
- **Body Text**: FreeSans

## Best Used For

Environmental presentations, sustainability reports, outdoor brands, wellness content, organic products.
