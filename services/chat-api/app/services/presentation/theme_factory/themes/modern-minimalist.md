# Modern Minimalist

A clean and contemporary theme with a sophisticated grayscale palette for maximum versatility.

## Color Palette

- **Charcoal**: `#36454f` - Primary dark color
- **Ocean Blue**: `#2563eb` - Accent color for highlights, key cards, and emphasis
- **Slate Gray**: `#708090` - Medium gray for accents
- **Light Gray**: `#d3d3d3` - Backgrounds and dividers
- **White**: `#ffffff` - Text and clean backgrounds

## Color Roles (Recommended)

- **Primary visual anchor**: Use **Charcoal** (`#36454f`) for titles, dominant containers, and key structure.
- **Accent highlight**: Use **Ocean Blue** (`#2563eb`) for 1-2 key cards per page, icon tints, summary bands, and highlight borders. This is the "pop of color" that prevents the deck from looking like a grayscale printout.
- **Secondary structure tone**: Use **Slate Gray** (`#708090`) for subheadings, lines, and medium emphasis.
- **Light support tone**: Use **Light Gray** (`#d3d3d3`) for dividers and soft panel backgrounds.
- **Content surface**: Use **White** (`#ffffff`) for readable body content and data cards.

## Practical Usage Rules

- Keep each page restrained: **one dark anchor + one mid-tone + neutral surface**.
- Avoid stacking multiple gray tints with low contrast.
- Use light gray for separation, not for main message emphasis.
- Prefer simple rounded rectangles and strong alignment grids.
- Keep connectors thin (`1-2px`) and neutral in color weight.

## Suggested Layout Color Mapping

- **Cover / hero page**: charcoal hero band with slate-gray accents.
- **Agenda / timeline page**: white surface, charcoal nodes, slate-gray connectors.
- **Architecture / framework page**: white cards, charcoal titles, light-gray dividers.
- **Data / chart page**: charcoal primary series, slate secondary, light-gray grid/axis.

## Do / Don't

- **Do** prioritize typography hierarchy and whitespace.
- **Do** keep one clear focal region per page.
- **Don't** rely on many similar gray shades without contrast checks.
- **Don't** add decorative color accents that break minimalist tone.

## Typography

- **Headers**: DejaVu Sans Bold
- **Body Text**: DejaVu Sans

## Best Used For

Tech presentations, architecture portfolios, design showcases, modern business proposals, data visualization.
