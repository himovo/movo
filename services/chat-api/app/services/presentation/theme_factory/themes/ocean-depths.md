# Ocean Depths

A professional and calming maritime theme that evokes the serenity of deep ocean waters.

## Color Palette

- **Deep Navy**: `#1a2332` - Primary background color
- **Teal**: `#2d8b8b` - Accent color for highlights and emphasis
- **Seafoam**: `#a8dadc` - Secondary accent for lighter elements
- **Cream**: `#f1faee` - Text and light backgrounds

## Color Roles (Recommended)

- **Primary visual anchor**: Use **Deep Navy** (`#1a2332`) for hero bands, major containers, and high-contrast title zones.
- **Secondary structure color**: Use **Teal** (`#2d8b8b`) for section titles, dividers, and medium-emphasis blocks.
- **Highlight color**: Use **Seafoam** (`#a8dadc`) for trend lines, key data callouts, and subtle emphasis.
- **Content surface**: Use **Cream** (`#f1faee`) or white for readable cards and text-dense regions.

## Practical Usage Rules

- Keep each page to **1 dominant base + 1 accent + neutrals**.
- For high-density pages, prefer cream/white content cards over tinted full-page fills.
- Use seafoam as highlight, not as a large background wash.
- Prefer rounded rectangles for process nodes and cards; avoid oversized circles as primary structure.
- Keep connector lines clean (`1-2px`) and place them behind nodes in timeline layouts.

## Suggested Layout Color Mapping

- **Cover / hero page**: navy base with teal + seafoam accents.
- **Agenda / timeline page**: light neutral surface, teal primary nodes, seafoam emphasis on current step.
- **Architecture / framework page**: cream/white cards, navy headings, seafoam micro-highlights.
- **Data / chart page**: hierarchy with navy, teal, seafoam, and neutral backgrounds.

## Do / Don't

- **Do** maintain calm contrast and generous whitespace.
- **Do** reserve navy for focal anchors and major containers.
- **Don't** overuse seafoam as broad panel background.
- **Don't** mix all four colors at equal visual weight on one page.

## Typography

- **Headers**: DejaVu Sans Bold
- **Body Text**: DejaVu Sans

## Best Used For

Corporate presentations, financial reports, professional consulting decks, trust-building content.
