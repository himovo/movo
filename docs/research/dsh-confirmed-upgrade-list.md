# movo 已确认可升级功能

核对日期：2026-11-06。判定对象是 movo 当前产品实现，而非 DSH 包内是否存在同类功能。逐 tag 发布条目仍见 `dsh-release-feature-inventory.md`。以下只保留经过前端入口、API 和关键交互流程核对后，能够明确说出“已有基础 / 缺少哪些行为”的项目。没有把性能、兼容性或仅凭关键词搜索的候选项列入。

## 1. 消息引用到输入框

- DSH：0.2.2-alpha.2、0.2.2-rc.1。
- movo：**未有**。目前单条消息支持复制和创建定时任务，没有“引用这段消息”操作；输入框没有来源引用卡，发送消息的数据结构也没有该引用。
- 需求：用户选中消息或其中一段文字，点击“引用”，输入框出现可移除的引用卡，保留原消息定位；发送后消息中显示紧凑预览，点击可回到原文。引用随草稿保存，发送失败不丢失。中文、英文文案齐备。
- 例子与价值：用户针对三周前的一条验收要求提出修改，不必复制整段历史，也不易误指别的要求。

## 2. 一键复制完整会话为 Markdown

- DSH：0.2.2-alpha.2、0.2.2-rc.1。
- movo：**未有**。已有单条消息复制和会话分享链接，但没有完整会话的 Markdown 导出入口。
- 需求：在会话菜单中增加“复制为 Markdown”，按时间顺序包含用户与助手文本、时间、可用的文件引用和原始日志路径；处理长会话分页和已压缩历史；复制前显示隐私提示及可选范围。中文、英文文案齐备。
- 例子与价值：把一次故障排查的完整过程贴到工单，减少人工逐条整理。

## 3. 附件预上传与逐个进度

- DSH：0.1.3-alpha.1、0.1.5-rc.1、0.2.2-rc.1。
- movo：**部分已有**。能附加图片和文档并显示本地预览，但点击“发送”后才串行上传；当前上传接口与输入框没有逐文件进度、取消及会话切换续显。
- 需求：选取文件即开始上传，每项显示等待、进度、完成、失败和重试；发送复用已上传结果；切换会话再返回仍看到上传状态；不允许取消一个已被消息提交的文件。中文、英文文案齐备。
- 例子与价值：用户上传多个大型报告时可以继续写提示、发现失败文件并单独重试，避免发送后长时间无反馈。

## 4. 发送失败时保留完整草稿

- DSH：0.2.2-rc.1。
- movo：**部分已有**。并发运行导致的特定 409 冲突会恢复草稿，但输入框在发送前先清空；额度检查、上传失败和一般请求失败没有同等的完整恢复路径。
- 需求：服务端确认接收前维持待发送状态；失败时恢复文字、引用、图片、文档、所选技能和知识引用；允许用户改动并重试；避免已入库消息因网络断线被重复提交。中文、英文文案齐备。
- 例子与价值：上传最后一个附件失败时，用户不必重写已经输入的详细任务说明。

## 5. 插件包更新与失败回滚

- DSH：0.2.2-alpha.2、0.2.2-rc.1。
- movo：**部分已有**。现有插件页支持安装、上传、验证、启停和删除；没有面向已安装插件的“更新”操作或更新 API，也没有热更新失败后恢复旧版本的产品流程。
- 需求：显示当前版与可用新版，允许从原来源或新包更新；更新前保存原包与配置；失败时自动回滚并给出诊断；成功后刷新可用工具与技能状态。中文、英文文案齐备。
- 例子与价值：团队更新插件发现新版本无法加载时，系统恢复旧版本，现有任务无需人工重装才能继续。

## 6. 会话归档与恢复

- DSH：0.1.6-alpha.1、0.1.7-alpha.1、0.1.7-rc.1。
- movo：**部分已有**。会话可置顶、搜索、改名和删除；当前用户端没有归档、已归档筛选、恢复的操作及 API。插件安装包字段中的 `archive` 与会话归档无关。
- 需求：会话菜单提供归档；侧栏与搜索可筛选已归档并恢复；运行中会话归档时列出受影响任务并要求确认，避免无声停止。中文、英文文案齐备。
- 例子与价值：项目结束后隐藏旧会话但保留历史；日后可以找回，不必在“保留杂乱列表”和“永久删除”之间二选一。

## 7. 单轮 Token 和耗时明细

- DSH：0.1.2-alpha.1、0.1.2-alpha.2、0.1.2-rc.1、0.2.2-rc.1。
- movo：**部分已有**。有独立的用量统计页和执行过程耗时；聊天中每条已完成回答后没有可展开的精确输入/输出 Token、缓存命中和本轮耗时组合明细。
- 需求：每轮回答尾部展示简短用量和耗时；点击展开模型、输入、输出、缓存及工具耗时。后端缺项时明确显示“不提供”，不从全局统计倒推。中文、英文文案齐备。
- 例子与价值：用户看到一次回答比平时贵，直接在该轮判断原因，而不必去独立统计页匹配请求。

## 已确认具备、因此未列为新建项

- 会话置顶和搜索。
- 工作树选择、本地文件差异树和逐文件审阅。
- 定时任务页面与编辑器。
- 快捷键设置页。
- 基础插件安装、启停和删除。

这些现有能力仍可能有细节差异，但不能把它们作为“movo 没有”的功能推荐。以上七项是当前静态代码核对中结论最稳的产品升级项；其中“部分已有”明确指基础能力存在、列出的具体行为缺失。实施时只修改 movo 代码，不修改 DSH 源码。
