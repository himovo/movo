# movo 对照 DSH 的升级需求

> 本文是初步规划，包含需要运行验收的候选项。经过进一步代码核对后，可作为当前实施依据的项目请见[已确认可升级功能](dsh-confirmed-upgrade-list.md)。

核对日期：2026-11-06。基线以 `services/chat-api/dsh/compatibility-matrix.yaml` 的 `active_release: 0.2.1-alpha.1` 为准。DSH 最新 tag 为 `dsh-v0.2.2-rc.1`。这里的“缺口”指 movo 产品入口或完整行为的缺口，不等于上游运行时没有能力。逐 tag 原始条目见[清单](dsh-release-feature-inventory.md)。

## 优先级 P0：直接影响任务完成和数据可靠性

1. **发送确认、失败保留与预上传**（0.2.2-rc.1，0.1.2-alpha.1，0.1.3-alpha.1）。需求：附件进入输入框即上传，显示每个文件进度和取消；消息经服务端确认接收才进入历史并清空草稿；发送失败完整保留文本、引用、附件；切换会话后继续显示上传状态。movo 当前在发送流程中才串行上传图片和文档（`useChatRuntimeStore.ts:660-757`），输入框仅保留本地图片预览（`ChatComposer.vue:281-296`）。例：上传多张 40 MB 截图时用户切换会话，仍能看到进度，失败后不必重写长提示。价值：避免丢稿和重复上传。
2. **对话连接状态与恢复**（0.1.2-alpha.2、rc.1；0.1.3-alpha.2）。需求：明确显示断线/重连中/已恢复，指数退避自动重试，并提供立即重连；恢复后按事件游标续读，不重复消息；运行计时暂停。movo 已有 `useSessionLiveStream.ts` 的事件游标及断线处理，缺少已核实的完整可见状态与手动恢复入口。例：地铁网络切换后能辨别 Agent 仍在执行还是已经停止。价值：降低误重试和重复任务。
3. **长会话回合导航和折叠过程**（0.1.2-alpha.1、alpha.3、rc.1；0.1.7-alpha.1；0.2.2-rc.1）。需求：完整历史索引覆盖未加载分页；点击按需加载定位；连续思考/工具调用成组折叠，提供“全部文字/仅最终答案”切换；跳转后滚动位置稳定。movo 有聊天流与独立用量页，未见等同的完整回合导航与过程展示偏好。例：200 轮调试对话中直接跳到第 17 轮的决策。价值：减少翻找成本。
4. **模型与 DSH 兼容升级门禁**（0.2.1-rc.2；0.2.2-rc.1）。需求：先在隔离分支升级 host 依赖与适配层，验证历史会话恢复、工具/审批、图片、搜索、流式与工作树，再逐步发布；不能修改 DSH 源码。现有兼容矩阵固定 `0.2.1-alpha.1`，`0.2.2` 将最低 Node 提高到 24.9，和矩阵当前 `^22.19.0 || >=24.0.0` 不兼容。例：直接升级会因运行时版本或事件协议改变导致生产会话无法续跑。价值：把功能升级变成可回滚的产品升级。
5. **权限审批与后台任务可见性**（0.1.7-alpha.1、rc.2；0.2.1-rc.1；0.2.2-rc.1）。需求：运行中的任务可确认停止，长命令转后台后继续显示状态；自动审阅拒绝时在允许人工审批的策略下呈现继续入口；用户插话能解除等待并保留后台任务。movo 有工具审批组件与运行状态，尚需端到端核实这些具体状态机。例：耗时 20 分钟的导出任务不应占死聊天输入。价值：减少任务中断。

## 优先级 P1：高频可见能力

6. **引用消息与完整历史复制**（0.2.2-alpha.2、rc.1）。需求：选中任意聊天文字插入输入框并保留来源，发送后显示紧凑引用预览；导出会话为 Markdown，按轮次包含角色、时间、文件链接和可用的原始日志路径。movo 现有 `UserMessageActions.vue` 仅复制单条消息，未见引用插入与完整历史复制。例：引用三周前的一段需求让 Agent 按该版本修改，或将完整讨论交给审计同事。价值：减少上下文重述。
7. **统一上下文菜单与键盘操作**（0.2.2-alpha.3、rc.1）。需求：会话、工作区、文件侧栏使用统一右键菜单模型，键盘可打开、导航和关闭；菜单保持在视口内，支持扩展项。movo 相关操作分散在侧栏按钮和工具栏，未见统一菜单注册层。例：触屏、键盘和鼠标用户都能找到“复制路径/定位/归档”。价值：提高可发现性及无障碍性。
8. **文件预览目录树与定位**（0.1.5-alpha.2；0.1.6-alpha.2；0.2.2-alpha.3、rc.1）。需求：预览 Markdown、代码、PDF、图片、Office 时保留目录树；聊天文件行号链接定位并短暂高亮；刷新后保留阅读位置；可拖动大图、交付原文件。movo 已有产物预览和工作区差异视图，但未见统一预览树与位置记忆。例：审阅长 Word 附件时，从聊天链接跳到指定文件并继续上次阅读位置。价值：减少重复定位。
9. **插件发现、升级与故障恢复**（0.1.6-alpha.2；0.2.1-alpha.4、rc.1；0.2.2-alpha.2、rc.1）。需求：富文本详情、自定义索引源、第三方包更新、热更新失败回滚、安装失败完整诊断；更新后技能菜单和依赖同步。movo `MyPluginsPage.vue` 已支持安装、验证、启停、删除，但未见更新与回滚 UI/API。例：插件新版本异常时自动恢复旧版本，用户不用手工重装。价值：降低扩展生态维护成本。
10. **插件辅助创建与推荐**（0.2.1-alpha.1、rc.1；0.2.2-rc.1）。需求：插件页“让 Agent 创建插件”保留草稿，发送后才执行；回答下方可按需展示官方插件启用或个性化页面卡片；用户能关闭推荐。movo 有插件管理和技能编辑，未见该组合式引导。例：用户说“每周汇总 Jira”，系统引导创建或安装适合插件。价值：缩短首次使用路径。
11. **思考翻译与开发者统计**（0.2.1-alpha.2；0.2.2-rc.1）。需求：实验性翻译插件可切换服务，原文与译文明确分隔；统计视图按轮次/步骤显示上下文、缓存、模型与工具耗时。movo 有总 token 用量页，未见等同的逐步骤诊断视图。例：定位一次任务变慢是模型响应还是工具调用。价值：提升诊断效率。
12. **工作树与审查闭环**（0.1.7-alpha.1；0.2.1-alpha.2；0.2.2-alpha.3、rc.1）。需求：在隔离 worktree 中运行会话；本地和 PR 差异统一搜索、逐文件导航；选中行和评论发送给 Agent；检查与评审状态回到同一界面。movo 已有 worktree 选项、`WorkspaceChanges.vue` 文件树和 `UnifiedDiffView.vue`，缺少已核实的 PR 评论与检查状态闭环。例：审阅者选中一段安全问题直接派给 Agent 修复，再看检查结果。价值：减少多工具切换。
13. **会话归档全流程**（0.1.6-alpha.1；0.1.7-alpha.1、rc.1）。需求：侧栏置顶、归档、筛选、搜索恢复；归档运行中会话须列出受影响的任务、子代理、提醒并确认“停止并归档”。movo 侧栏已支持置顶和搜索，未找到归档/恢复的完整路径。例：清理旧项目时不误停仍在运行的定时任务。价值：会话列表可管理且安全。
14. **自动化任务统一管理**（0.1.7-rc.2；0.2.2-rc.1）。需求：手动创建、直接编辑、从聊天预填，保留编辑草稿；运行记录、冲突复核、会话复用或新建；一次清除已结束任务。movo 已有 `ScheduledTaskPage.vue` 和编辑器，需要逐项补齐冲突与清理等行为。例：改动每周报告时间时避免覆盖另一端的并发编辑。价值：提高计划任务可靠性。
15. **手机和平板布局**（0.2.2-alpha.2、alpha.3、rc.1）。需求：侧栏、菜单、模型目录、插件发现、软键盘下的输入框保持可操作；同名工作区显示最短区分路径；窗口缩小后悬浮面板保持可达。movo 已有响应式样式，但未做这组设备矩阵验收。例：平板横竖屏切换后仍能完成插件安装。价值：移动端可用性。
16. **会话内统计与模型选择精细化**（0.1.2-alpha.1；0.2.1-alpha.4；0.2.2-rc.1）。需求：每轮结束显示精确 token、耗时、缓存命中；模型列表搜索/筛选/拖动排序、保留自定义参数，设置推理等级。movo 有全局用量页和模型选择器，未见完整的每轮统计与排序交互。例：用户比较两次回答的缓存命中和费用。价值：可解释的成本控制。

## 优先级 P2：可按产品定位取舍

17. **多语言扩展**（0.1.2-alpha.1；0.2.2-alpha.2、rc.1）。DSH 增加日语、西班牙语、法语、德语、俄语、巴西葡萄牙语。movo 目前至少有中英语言设置；若扩展语言，所有新增前端入口必须同时覆盖中英，其他语言仅在产品决定支持时纳入。价值：避免界面混用语言。
18. **桌面首次引导、更新与系统权限**（0.1.7-rc.2；0.2.0-rc.1；0.2.2-rc.1）。需求：首次引导解释额度和工作过程偏好；更新提示显示版本、下载与重试；macOS Computer Use 权限指导并刷新状态。movo 有桌面更新卡和服务配置，首次引导及系统权限路径需按自有产品架构评估。价值：降低安装与授权失败率。
19. **CLI、SDK 与 ACP 对外接口**（0.1.2-alpha.1；0.1.6-alpha.1；0.2.2-rc.1）。如果 movo 对外开放这些模式，再规划标准输入任务、会话续跑、逐行 JSON、权限回调和资源 API；当前不能仅因 DSH 支持就宣称 movo 已有。价值：支持企业自动化和第三方集成。

## 验收口径

所有新增前端功能必须同时提供中文和英文文案；源码不写中文常量，使用现有 i18n。DSH 包保持只读，改动仅落在 movo 适配层和产品 UI。每项上线前至少验证正常、失败、刷新恢复、历史会话和窄屏五种场景。性能类优化需建立同一数据集的升级前后基线，静态代码检索不能判定已达标。
